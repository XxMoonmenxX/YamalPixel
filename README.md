Python minecraft launcher
Лаунчер для майнкрафта на питоне
дискорд - https://discord.gg/yF3QdGnMj4


Запуск текущего интерфейса: `python run.py`.

Готовая сборка YamalPixel устанавливается из одного ZIP Яндекс Диска,
заданного в `CONFIG['mods_archive_url']`. При запуске показаны скачанные МБ,
прогресс загрузки/распаковки и названия модов. Архив кэшируется; при изменении
его MD5 скачивается заново. Только проверенные JAR переносятся в mods после
подготовки и резервного копирования, при ошибке текущие моды сохраняются.
Старые списки индивидуальных ссылок готовой сборки удалены.

Пользовательские инструкции находятся в меню «Гайд» рядом со «Справкой» (F1).
Гайд содержит поиск, объяснение главного окна, всех пунктов «Инструменты»,
создания/редактирования сборок, Java, загрузок и действий при ошибках; интернет
для чтения не нужен.

Загрузки Яндекс Диска используют свежие временные ссылки и повторную попытку
при сбое. Ответы прокси для JAR/ZIP проверяются до замены файла; HTML-страница
не считается скачанным модом/шейдером, и загрузка продолжается напрямую.
ZIP шейдеров сохраняется в shaderpacks без автоматической распаковки.

Сборка EXE (Windows, Python 3.12–3.14):

```powershell
python build.py --install-deps
```

Получится `dist/nuitka/YamalPixelLauncher.exe`. Python на компьютере получателя
не нужен; Java для Minecraft лаунчер проверяет отдельно. `--install-deps`
устанавливает зависимости в тот Python, которым запущен скрипт; рекомендуется
использовать виртуальное окружение проекта. Повторная сборка: `python build.py`.
Если `python` в Windows не запускает установленный Python, используйте
`py -3.14 build.py --install-deps` или полный путь к `python.exe`.

Для диагностики: `python build.py --standalone --console`. Результат —
`dist/nuitka/run.dist/YamalPixelLauncher.exe`; переносится вся папка `run.dist`.
`--dry-run` показывает команду, `--jobs 4` ограничивает параллелизм,
`--output-dir путь` меняет папку результата. Перед пересборкой закройте EXE.
MSVC Build Tools с компонентом C++ нужен для компиляции; Nuitka может предложить
скачать поддерживаемый компилятор для вашей версии Python.

После компиляции скрипт запускает EXE в отдельном временном профиле и проверяет
ресурсы, зависимости, интерфейс создания сборки, сигналы QThread и локальные
моды. Эта проверка не запускает Minecraft и не обращается к сетевым сервисам.
Отчёты сохраняются в `dist/nuitka/compilation-report.xml` и `smoke-test.json`.
Ошибки обычного запуска без консоли записываются в `~/YamalPixel/logs/launcher.log`
и `launcher-console.log`. Пользовательские сборки и данные игры находятся
в домашней папке пользователя и не включаются в EXE.

Для своих модов откройте создание сборки и выберите «Кастомная сборка — локальные
моды». Укажите Minecraft и загрузчик, затем добавьте JAR-файлы, папку `mods`
(или корневую папку сборки с `mods`) либо ZIP с JAR-модами. После сохранения
выберите сборку с префиксом 📦 в главном окне и запустите игру.
Локальные моды копируются в `collections/local_mods`, исходные файлы больше
не нужны. Зависимости добавляются вручную; версия игры и загрузчик должны
подходить модам. Настройки, ресурсы и архивы с одним лишь манифестом без JAR
этим режимом не импортируются. При переносе сборки нужны её JSON и папка
`local_mods` из хранилища сборок.

Редактирование: в менеджере сборок выберите сохранённую сборку и нажмите
«Редактировать». Можно удалить несколько выбранных модов (Ctrl/Shift), добавить
JAR/ZIP/папку или найти моды в Modrinth/CurseForge. Режим «Смешанная сборка»
показывает поиск в каталогах и импорт локальных файлов одновременно.
«Сохранить изменения» обновляет исходный файл сборки, сохраняя описание,
дату создания и закреплённые версии оставшихся модов. «Отмена» оставляет
сохранённую сборку без изменений. Изменения состава применяются к игре при
следующей установке/запуске сборки.

Проект использует собственную библиотеку `MCLIB/` (на основе minecraft-launcher-lib 8.0).
Импорты и конфигурации сборки переведены на локальную библиотеку; отдельный пакет
minecraft-launcher-lib для запуска не требуется. Лицензия и авторство оригинала сохранены.

Каталог Minecraft и доступных загрузчиков обновляется при запуске из официальных API.
Галочка «Показывать бета версии» включает предварительные версии игры и загрузчиков.
Без сети используется последний сохранённый каталог. Установка сборки подготавливает
моды во временной папке и заменяет текущие только после полной загрузки и бэкапа.

Проверки: `python -m unittest discover -s tests -v`.

При запуске окно в фоне проверяет `/api/v1/health` настроенного прокси (короткий таймаут).
Доступный прокси получает приоритет при загрузке модов и шейдеров; при отсутствии
ответа используются прямые источники. Пока проверка не закончилась, загрузки также
идут напрямую. При сетевом сбое прокси отключается для оставшихся загрузок текущего
запуска. Закреплённые версии модов сохраняются при переключении источника.
